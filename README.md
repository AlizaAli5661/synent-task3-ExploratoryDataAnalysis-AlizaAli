# Netflix Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset.

The objective is to understand the dataset, identify patterns and trends, and visualize important insights using Python.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## 📂 Project Files

- `netflix_titles.csv` – Original Netflix dataset
- `netflix_cleaned.csv` – Cleaned and processed dataset
- `eda.ipynb` – Complete EDA notebook
- `Graphs/` – Visualizations generated during the analysis

## 🔍 Analysis Performed

- Dataset overview and statistics
- Missing value analysis
- Duplicate record detection
- Movies vs TV Shows analysis
- Content rating analysis
- Release year analysis
- Movie duration analysis
- TV Show seasons analysis
- Country-wise content analysis
- Genre analysis
- Titles added to Netflix over the years
- Movies vs TV Shows by release year
- Correlation analysis

## 📊 Visualizations

The project contains visualizations for:

1. Movies vs TV Shows
2. Content Ratings
3. Titles by Release Year
4. Movie Durations
5. TV Show Seasons
6. Top Countries
7. Top Genres
8. Movies vs TV Shows by Release Year

## 📈 Key Insights

- Movies make up the majority of Netflix's content.
- TV-MA and TV-14 are among the most common content ratings.
- Most movies fall within a typical feature-film duration range.
- Many TV shows have relatively few seasons.
- Netflix content has grown significantly over recent years.
- The dataset contains content from many countries and genres.
